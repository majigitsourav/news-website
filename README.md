📰 News Portal Web Application:

📌 Project Overview
A full-stack news portal web application that allows users to browse, filter, and interact with news articles.
The application provides category-based filtering, detailed news views, user comments, and QR code generation for each news article.
An admin approval system ensures only verified news is published.

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: Django
Database: SQLite3

✨ Features
👤 User Features
-> User registration and login using Django’s built-in authentication system
-> Browse news articles by categories such as Sports, Songs, Entertainment, etc.
-> View detailed news content on a separate page
-> Comment on news articles
-> QR code generated for each news article
-> Automatic view count tracking for every news post

🔐 Admin Features
-> Secure admin panel for managing news content
-> Admin approval system: only approved news is displayed on the UI
-> Custom admin panel designed and implemented for better content control
-> Manage users, news categories, and comments

⚙️ Key Functionalities
-> Category-based filtering for improved user experience
-> QR code integration for easy sharing of news articles
-> View counter to track article popularity
-> Role-based access control (Admin & User)
